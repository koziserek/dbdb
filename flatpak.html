dbdb as a Flatpak

This is the Flatpak repository of dbdb, an ETL and data migration tool. It holds version 0.50.0. To install it, for Linux on x86_64:

flatpak install --user https://koziserek.github.io/dbdb/dbdb.flatpakref

Later versions then come with flatpak update, or from your software centre with its other updates.
